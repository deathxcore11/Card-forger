CARDFORGE 2.4 UPDATE

- Official mana symbols everywhere. Mana costs, color identity, color balance, the mana base table
  and card rules text ({T}, {G}, {2} …) now use the real Magic symbol artwork from Scryfall instead of
  lettered circles. If a symbol can't load (offline), its {W}-style text shows instead.
- Set pages. Tap any set badge — in deck rows, search results, the collection, or the set name in a
  card's details — to see every printing in that set as a clean card-image grid, in set order. Shows
  how many you own (green outline and ×count for exact printings, "other ed." if you own a different
  printing), and lets you search, filter Owned/Missing, filter by rarity and sort by price. Tap a card
  for its details, Buy links and "I own this", which now pre-fills that exact set and collector number.
- All sets. Search → "Browse sets" (or ⚙ → Browse every set) lists every paper set, newest first,
  grouped by year, with promos/tokens/extras behind a switch. The list comes live from Scryfall and
  refreshes every few days, so new sets show up as soon as Scryfall adds them.
- Correct set symbols. Set icons now come from Scryfall's set list, which fixes missing symbols for
  Secret Lair, The List, promos and similar sets.
- Card popups can no longer scroll sideways.

CARDFORGE 2.3 UPDATE

- Deck review badge. Under each deck's name: "▲ 3 to review" (amber) or "● 2 to review" (red when a
  rule is broken). Tap it for one list: card count (empty slots, kept separate from cards you still
  need to buy), cards outside your colors, illegal cards, too many copies, cards with no data, and,
  once the list is nearly complete, guideline checks for lands, ramp, draw, removal and tapped lands.
  Each item shows its evidence, says whether it's a Rule or a Guideline, and has a fix button.
- Buy this card. Tap any price in a card's details, a printing's "Buy" button, or a price in the
  Shop tab. Shows the exact printing (set, number, language, finish), the Scryfall estimate with its
  date (plus the Cardmarket euro trend when available), direct "View listing" links for that exact
  printing on TCGplayer and Cardmarket, clearly labeled name searches, "Compare cheaper printings",
  and a separate "Add to collection" button. Opening a store never changes your collection. Stock,
  shipping and seller prices are only shown on the seller's site.
- Smoother popups. The page behind no longer scrolls, focus returns to the button you tapped when a
  popup closes, and going back from "Buy this card" returns you to the same spot in the card details.

CARDFORGE 2.2 UPDATE

- Commander bracket estimate (Deck → Engine). Shows the lowest bracket (1–5) the list fits by
  Game Changers, tutors, extra turns and mass land denial, what Cardforge counted, and what to
  cut to drop a bracket. It's a starting point for Rule 0 talks: two-card combos and play style
  aren't detected.
- Mana base helper (Deck → Engine). Suggests a basic-land split from the colored mana symbols in
  your spells and lists lands that always enter tapped.
- Life tracker (Deck → Playtest). 2–6 players at 40 life (20 for 60-card decks), commander damage
  (also comes off life, 21 is lethal), poison (10 is lethal) and a turn counter. "I won / I lost"
  saves the game to the deck's log with the ending turn.
- Proxy print sheet (Deck → Shop, or ⋯ menu for the whole deck). 9 cards per page at real card
  size for playtesting. Basic lands are skipped.
- Publishing: the project now lives on GitHub with automatic tests. Cloudflare can deploy straight
  from GitHub (see README.md); GitHub Pages is available as a second address.

CARDFORGE 2.1 UPDATE — October 12, 2026

- Opening a deck idea now builds a proposed full deck with lands and missing cards. The default purchase budget is your workspace budget (normally $25); you can change it.
- Save entire deck includes every listed card and all basic-land quantities. No automatic ownership changes.
- Custom budgets in suggestions, slot filling and upgrades support values above $100 (up to the app's $100,000 validation limit).
- A dollar budget is separate from Commander's 100 total cards. Lands count toward those 100 cards.
- The planner reserves money for the remaining spells rather than using the budget on an early expensive recommendation. Owned-only mode remains available and can be incomplete.
- Random Card buttons on Home and Search. Random Deck buttons on Home and Decks; previews require review before saving.
- Set badges include readable set codes and rarity-colored symbols in card rows, grids and suggestions. Draft/search badges identify reference printings. Collection entries without a recorded set show SET ? rather than inventing a physical edition.
