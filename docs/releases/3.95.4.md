# CardStashy website 3.95.4

Website-only release candidate, October 24, 2026. Publication and live-byte
verification are still pending at this record's preparation. This is the
owner-approved interim Home/deck-building update; it is not completed 4.0 Play.

## Included

- One continuous Home artwork surface and a compact desktop header. Card of
  the Day/collectible packs precede collection value and recent personal decks,
  followed by Community Meta decks and news.
- Shared detailed list, overlapping stacks, full-card grid and names-only deck
  views. Original card actions, printing/finish identity, quantities, zones and
  selection survive display changes.
- Magic main-deck quantities and constructed size are separate from sideboard
  counts; whole-deck purchase/ownership comparisons can still include both.
- Generated results retain export, card inspection/Back and rebuild access
  after display-only preference writes. Meaningful workspace/account/deck/price
  changes continue to invalidate stale results.
- Ninja/Ninjutsu leader discovery recognizes Commander ninjutsu and grants to
  creature cards in your hand, preserves an explicitly selected commander,
  and can reuse verified same-theme cards after empty searches. A no-results
  response is distinguished from an outage; this is bounded discovery coverage,
  not certification of a complete competitive Ninja list.
- Structured deck-reference guides no longer turn descriptive card names or
  alternative packages into mandatory themes. The primary plan and explicit
  requirements survive budget continuation, including No spending cap.
- The recovered Random Deck fixed-pattern parser/build-time repair and its
  identity/accounting safeguards remain included, alongside the bounded deck
  construction fixes described by the in-app release record.
- Header Play and daily-pack Draft entries are removed. Existing collectible
  pack opening stays available. The future desktop game is isolated on
  `codex/cardstashy-play-engine-20261024`, with its complete new-chat handoff.
- Internal documentation/experiments and the server-only matchup route are
  excluded from Cloudflare's static asset upload. The unused legacy GitHub Pages
  publisher is removed; production continues through the existing
  Cloudflare Git connection.
- Website version is 3.95.4, shell cache v317, with 229 preloaded modules and
  complete module-graph offline inventory. The APK is not rebuilt or replaced.

## Still open

and physical-device measurements remain separate work. Vehicle crew balance,
theme density and supported closing routes are not certified merely because
the builder runs faster or the list is full.

Play, CPU difficulties, broad card coverage, browser cold-offline match
recovery, match history/opponent copying, Draft and friend sessions are not
part of this website release. The full 4.0 game keeps its existing engine,
