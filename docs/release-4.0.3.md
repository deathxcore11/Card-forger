# PC hotfix 4.0.3

Deck selection now checks installed rules before launch, and the installed executable database grows from 6,137 to 36,037 records. Original lists and selected printings are preserved. Combined card faces such as The Arkenstone // Seek the Heart resolve against their shared identity.

The setup screen has a visible tested starter match, direct Commander precon navigation, actionable deck seats, and compact support failures with expandable diagnostics. Rules available means definitions are installed; it does not certify every interaction.

CPU opponents can answer spell-mode, named-option, combat-tax and commander-zone choices. These decisions use engine-offered actions and the CPU seat's authorized information. Loot's private reveal and remainder ordering correction is included.

Smart mode is the default, with Smart / Full Control visible in the decision dock. A bounded response check for the shipped engine advances verified empty response windows without repeated Continue clicks. Instants, flash, activated abilities, floating mana, required choices, custom stops and unfamiliar permission effects retain a stop. This is not a universal response proof for every card; it never treats the CPU's incomplete suggestions as the full legal action set.
